📖 Tech Blogs - Blog Management System

A responsive full-stack Blog Management Web Application built using HTML, CSS, JavaScript, Node.js, and Express.js. The application allows users to create, read, update, delete, search, and manage blog posts through an intuitive and user-friendly interface.

🚀 Live Features

🏠 Home Page

Display latest blog posts

Responsive blog cards layout

Search blogs instantly

Edit and Delete functionality

Undo Delete notification

📝 Add Blog

Create new blog posts

Client-side form validation

Category selection

Tags support

Blog image URL support

📄 Blog Details

View complete blog content

Author information

Category badge

Featured blog image

✏️ Edit Blog

Update existing blogs

Pre-filled form data

Save changes instantly

🗑️ Delete & Restore

Delete blogs with confirmation

Undo delete functionality using toast notification

🔍 Search Functionality

Real-time blog search

Search by title and content

📱 Responsive Design

Mobile-friendly layout

Tablet compatibility

Responsive navigation menu

⚙️ Installation & Setup

Clone Repository

git clone https://github.com/Arpitagho/Simple-Blog-Manager-ag.git


Navigate to Project Folder

cd Simple-Blog-Manager-ag

Install Dependencies:  npm install

Run Server:  node main.js

Open Browser:  http://localhost:3000

🔗 API Endpoints

Method	Endpoint	Description

GET	/api/blogs	Fetch all blogs

GET	/api/blogs/:id	Fetch single blog

POST	/api/blogs	Create blog

PUT	/api/blogs/:id	Update blog

DELETE	/api/blogs/:id	Delete blog

POST	/api/blogs/restore	Restore deleted blog
